Overview

What this subsystem does

The autonomous subsystem is a MoveIt 2 pick-and-place layer. It exposes /holoassist/pick_cube_to_bin, accepts a cube name and destination bin, transforms the selected cube pose into base_link, then queues a full autonomous sequence: home, approach, open, descend, grip, lift, move to bin, place, release, retreat.

The implementation matches the High Distinction target by supporting repeated cube/bin requests without manual reset, four parameterised bin destinations, a MoveIt planning scene with floor safety and block collision updates, and timestamped JSON status output for sort progress, success/failure, and cycle-time analysis.

State Machine

Pick-and-place sequence

Every pick triggers this six-stage state machine. Cartesian path attempted first; falls back to MoveIt OMPL pose-goal on failure.

PREGRASP → move to hover above cube (pregrasp_z_offset = 0.10 m above cube Z) GRASP → gripper open → descend → gripper close LIFT → ascend back to hover (cube attached in planning scene) MOVE_TO_BIN → joint-space move above bin → Cartesian descent PLACE → gripper open → cube released from planning scene RETREAT → ascend to safe pose
Monitor progress: ros2 topic echo /pick_place/status — publishes timestamped JSON at each stage.

Known Issues

Troubleshooting

  • Service returns false: no cube pose
    The pick service has not received /holoassist/perception/april_cube_N_pose. Start perception, show the cube to the camera, and confirm the workspace TF is available.
  • Queued request succeeds but the pick later fails
    /holoassist/pick_cube_to_bin queues the request; watch /pick_place/status for the real step-by-step result, failure reason, and timestamped metrics.
  • Plan succeeds but the arm does not move
    Switch the dashboard to MOVEIT mode so scaled_joint_trajectory_controller and finger_width_trajectory_controller are active. On URSim or hardware, External Control must also be running.
  • External Control speed limit or protective stop
    Keep velocity_scale:=0.05. If Cartesian descents are still too aggressive, set cartesian_retime_velocity_scale:=0.03 for slower straight-line paths.
  • Pick or place height is off
    Tune grasp_z_absolute, pregrasp_z_offset, and place_z_offset. If XY is also wrong, re-check the workspace_frame → base_link calibration and bin_poses.json.
