What this is

HoloAssist is a complete teleoperation and autonomous manipulation stack for the Universal Robots UR3e, built on ROS 2 Humble. It bridges a Unity-based HoloLens interface to the physical robot through a ROS-TCP endpoint, with auto-discovery so the headset finds the robot without configuration.

The system sees objects through Intel RealSense depth cameras and AprilTag fiducial markers, fuses their 6-DOF poses in real time, and feeds them to MoveIt 2 for collision-aware motion planning. An operator can teleoperate directly, or trigger autonomous pick-and-place with a single service call.

Everything launches from one script. Real robot or simulated hardware, with or without cameras, with or without the dashboard—same command, different flags. The launcher handles startup ordering, health checks, and coordinated shutdown.

Capabilities

What the system does

Teleoperation
Direct joint and Cartesian control from the mixed-reality headset, with OnRobot RG2 gripper force feedback and hardware-level e-stop.
  • Real-time joint + Cartesian modes
  • Seamless real/simulated hardware switch
  • Force-feedback gripper control
Mixed Reality
Unity-based HoloLens interface with holographic workspace overlays, radial menus, and a trolley scene with live 3D models.
  • ROS-TCP bridge with low latency
  • UDP beacon for zero-config discovery
  • Holographic workspace overlays
Perception
Multi-sensor pipeline with automatic camera fallback: RealSense, Brio, generic USB, or simulated. AprilTag detection with 6-DOF cube pose fusion.
  • 4-source camera cascade
  • AprilTag fiducial tracking
  • Debug overlay diagnostics stream
Motion Planning
MoveIt 2 consumes live cube poses and generates collision-aware trajectories. Pick-and-place triggered via a single ROS service call.
  • Collision-aware planning
  • Live pose-to-target adapter
  • Service-based pick/place API
Dashboard
PyQt operator panel showing live joint rates, gripper state, perception health, camera feeds, and e-stop controls.
  • Real-time system monitoring
  • Camera feed display
  • Emergency stop with resume
Calibration
Eye-to-hand calibration via easy_handeye2 computes the camera-to-base transform. Run once, persist, auto-publish on startup.
  • AprilTag-based estimation
  • Persistent calibration files
  • Auto static TF publishing
Stack

What it runs on

ROS 2 Humble
Robot middleware, DDS transport, lifecycle management
Unity 3D
HoloLens mixed-reality application runtime
MoveIt 2
Motion planning, manipulation, collision checking
Intel RealSense
Depth camera, point cloud, RGB-D perception
AprilTag
Fiducial marker detection and 6-DOF pose estimation
Universal Robots
UR3e 6-DOF industrial manipulator, ros2_control driver
OnRobot RG2
Collaborative parallel gripper, position + force control
Ubuntu 22.04
Target deployment platform for ROS 2 Humble
Quick start

Three commands to a working stack

Build
# clone + build
git clone https://github.com/John-A-Chen/HoloAssist.git
cd HoloAssist/main/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
Simulated
# no hardware required
./launch.sh \
  --perception \
  --moveit \
  --dashboard
Real Hardware
# connect to UR3e
./launch.sh \
  --robot-ip 192.168.0.194 \
  --perception \
  --moveit \
  --dashboard
