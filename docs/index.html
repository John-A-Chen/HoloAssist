Robot Control

Precision Teleoperation

Take direct control of the UR3e from your mixed-reality headset. Joint-level and Cartesian modes give you the flexibility to operate with surgical precision or broad strokes.

  • ✓ Real-time joint and Cartesian control via Unity
  • ✓ OnRobot RG2 gripper with force feedback
  • ✓ Seamless switch between real and simulated hardware
  • ✓ Emergency stop with hardware-level safety
Mixed Reality

Your Hands in the Loop

A Unity-powered HoloLens interface that overlays holographic controls directly onto the physical workspace. The robot becomes an extension of your intent.

  • ✓ ROS-TCP bridge with sub-second latency
  • ✓ UDP beacon for zero-config headset discovery
  • ✓ Holographic workspace overlays and radial menus
  • ✓ Trolley scene with live 3D model rendering
Computer Vision

Eyes on Every Object

A multi-sensor perception pipeline that detects, tracks, and fuses object poses in real time. From RealSense depth cameras to sim fallback, the system always sees.

  • ✓ 4 camera sources with automatic fallback cascade
  • ✓ AprilTag fiducial detection and 6-DOF pose estimation
  • ✓ Multi-cube pose fusion and TF publishing
  • ✓ Debug overlay and visual diagnostics stream
Autonomous Manipulation

Plan. Pick. Place.

MoveIt 2 motion planning consumes live perception data to autonomously pick objects and place them precisely. One service call from headset to complete manipulation.

  • ✓ Collision-aware trajectory planning
  • ✓ Live cube-pose-to-MoveIt target adapter
  • ✓ ROS service interface for pick-and-place
  • ✓ Safety checks and status monitoring
Operations

Full Situational Awareness

A real-time dashboard gives operators complete visibility into robot state, perception health, and system status. Emergency stop is always one click away.

  • ✓ Live joint rates, controller state, and gripper status
  • ✓ Perception topic health monitoring
  • ✓ Camera feeds and debug overlays
  • ✓ Hardware e-stop with resume logic
Precision

Millimetre-Accurate Calibration

Integrated eye-to-hand calibration computes the exact camera-to-base transform. Persist once, use every session. Your perception and manipulation stay perfectly aligned.

  • ✓ easy_handeye2 calibration workflow
  • ✓ AprilTag-based transform estimation
  • ✓ Persistent calibration files across sessions
  • ✓ Auto-published static TF on perception startup

Get Started

Up and Running in Minutes

Clone, build, and launch the entire stack with a single command.

terminal — build
# Clone the repository
git clone https://github.com/John-A-Chen/HoloAssist.git
cd HoloAssist/main/ros2_ws

# Build the workspace
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
simulation mode
# No hardware needed
./launch.sh \
  --perception \
  --moveit \
  --dashboard
real hardware
# Connect to UR3e
./launch.sh \
  --robot-ip 192.168.0.194 \
  --perception \
  --moveit \
  --dashboard
