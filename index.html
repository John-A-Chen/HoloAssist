System Architecture

Data flows from Brio camera through ROS 2 to the UR3e and Quest 3.

Brio / RealSense Camera │ /camera/camera/color/image_raw (30 fps) ▼ AprilTag Detector [apriltag_ros] │ /detections_all ▼ Cube Pose Node [20 Hz timer — TF race fix] │ /holoassist/perception/april_cube_N_pose (PoseStamped) │ /holoassist/perception/april_cube_N_bin_check │ freeze at last pos on tag loss ▼ MoveIt Pick-and-Place [scaled_joint_trajectory_controller] ▼ UR3e + OnRobot RG2 │ /joint_states TF tree ▼ RViz + ROS-TCP Endpoint :10000 │ Quest 3 (Unity) AR overlay + teleop controls
