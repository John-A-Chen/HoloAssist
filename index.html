Perception

AprilTag cube tracking · 20 Hz · 4 cubes · single-tag detection

AprilTag-based pipeline detecting up to 4 physical 40 mm cubes at 20 Hz. Single-face detection supported — multi-face consensus filter averages estimates within 5 cm. Positions freeze in RViz on tag loss. Camera-agnostic: RealSense, Brio 4K, or USB webcam.

Autonomous

MoveIt 2 pick-and-place · OnRobot RG2 · collision-aware planning

MoveIt 2 pick-and-place stack consuming live cube poses from perception. Generates collision-aware trajectories via OMPL, executes on the UR3e with the OnRobot RG2 gripper. Triggered by a single ROS service call with automatic pre-grasp, grasp, carry, and place sequencing.

03 / 04

Teleop­eration

Quest 3 hand-gesture control · ROS-TCP bridge · UDP auto-discovery

Hand-gesture control of the UR3e via Meta Quest 3 hand tracking. Unity C# classifies pinch and grip gestures, publishes commands over ROS-TCP-Endpoint on port 10000. UDP beacon handles IP auto-discovery so the headset connects without manual configuration.

Visua­lisation

Quest 3 AR overlay · Unity + AR Foundation · live ROS TF

Holographic twin of the robot workspace rendered in Quest 3 AR passthrough. The UR3e arm, trolley, and detected cubes are displayed as 3D overlays anchored to the physical scene. Joint states and cube poses flow live from ROS via ROS-TCP-Endpoint.

System Architecture

Data flows from Brio camera through ROS 2 Humble to the UR3e and Quest 3.

Brio / RealSense 30 fps │ /camera/color/image_raw ▼ AprilTag Detector [36h11 family] │ /detections_all ▼ Cube Pose Node [20 Hz timer — TF safe] │ /holoassist/perception/april_cube_N_pose │ /holoassist/perception/april_cube_N_bin_check │ 4 cubes · single-tag · freeze on loss ▼ MoveIt Pick-and-Place [scaled_joint_trajectory] ▼ UR3e + OnRobot RG2 │ /joint_states · TF tree ▼ RViz + ROS-TCP :10000 │ Quest 3 (Unity) AR overlay + teleop controls
